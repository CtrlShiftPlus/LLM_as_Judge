# LLM-as-a-Judge

## Overview

LLM-as-a-Judge is an AI response evaluation platform designed to assess the quality, reliability, and safety of responses generated by Large Language Models (LLMs). Instead of relying solely on a single evaluation metric, the system employs multiple independent evaluation modules ("judges") that analyze different aspects of an AI-generated response.

The platform combines traditional Machine Learning models, Natural Language Processing techniques, semantic similarity models, and an optional Large Language Model (Gemini) to produce a comprehensive evaluation report. The results are presented through an interactive web dashboard for easy interpretation.

This project demonstrates the integration of Machine Learning, Deep Learning, Natural Language Processing, and Full Stack Web Development into a unified AI evaluation system.

---

# Project Objectives

The primary objectives of this project are:

- Evaluate AI-generated responses using multiple independent quality metrics.
- Detect hallucinations and factual inconsistencies.
- Measure semantic completeness of responses.
- Identify toxic or harmful content.
- Assess readability and clarity.
- Compute consistency across evaluation modules.
- Generate a consensus score representing overall response quality.
- Optionally use a Large Language Model as a meta-evaluator for final verification.
- Present results through an interactive visualization dashboard.

# Evaluation Modules

## 1. Hallucination Judge

Purpose:

Measures semantic similarity between the expected answer and the generated response using Sentence Transformers.

Output:

- Score
- Status
- Risk
- Confidence
- Recommendation

---

## 2. Completeness Judge

Purpose:

Determines whether every topic requested in the prompt has been covered by the generated response.

Output:

- Covered Topics
- Missing Topics
- Completeness Score

---

## 3. Toxicity Judge

Purpose:

Detects offensive, abusive, or harmful language using a trained machine learning classifier.

Dataset:

Jigsaw Toxic Comment Classification Dataset

Algorithms Evaluated:

- Logistic Regression
- Linear SVM
- Naive Bayes

Output:

- Toxic / Non-Toxic
- Confidence
- Safety Score

---

## 4. Readability Judge

Purpose:

Measures readability using the Flesch Reading Ease formula.

Metrics:

- Word Count
- Sentence Count
- Reading Score

---

## 5. Consistency Judge

Purpose:

Evaluates whether the outputs of different judges are internally consistent.

---

## 6. Consensus Judge

Purpose:

Produces the overall evaluation score using weighted aggregation of all judges.

---

## 7. Master LLM Judge (Optional)

Purpose:

Uses Google Gemini to review all local judge outputs and generate an overall AI-based verdict.

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/CtrlShiftPlus/LLM_as_Judge

cd LLM-as-Judge
```

---

## 2. Backend Setup

Navigate to backend.

```bash
cd backend
```

Create virtual environment.

### Windows

```bash
python -m venv venv

venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv

source venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```

Run migrations.

```bash
python manage.py migrate
```

Start the Django server.

```bash
python manage.py runserver
```

Backend URL

```
http://127.0.0.1:8000/
```

---

## 3. Frontend Setup

Navigate to frontend.

```bash
cd frontend
```

Install dependencies.

```bash
npm install
```

Start development server.

```bash
npm run dev
```

Frontend URL

```
http://localhost:5173/
```
